# 百度文库 Word 去除无关内容

## 模板

结构参考：[office/doc/1779378613353.docx](../../../office/doc/1779378613353.docx)

| 段落索引 | 内容 | 处理 |
|---------|------|------|
| 0 | `百度文库` | 删除 |
| 1 | `搜索` | 删除 |
| 2 | 头像图片（`w:drawing`） | 删除 |
| 3 | 文档标题（如 `2025上半年中级软件水平考试《嵌入式系统设计师(综合知识)》真题卷(附详细解析)`） | **用作输出文件名** |
| 4+ | 正文 | 保留 |
| 版权段前一段 | 最后一张水印/装饰图 | 删除 |
| 含 `版权说明：本文档由用户提供并上传…` 的段及之后 | 相关推荐、猜你想看等 | 全部删除 |

版权说明锚点（**原文，勿改**）：

```
版权说明：本文档由用户提供并上传，收益归属内容提供方，若内容存在侵权，请进行举报或认领
```

## 工作流

1. 确认输入为 `.docx`（百度文库/脚本导出的 Word）。
2. **优先执行脚本**（与模板逻辑一致）：

```bash
python .cursor/skills/baidu-wenku-word-cleanup/scripts/clean_baidu_wenku_docx.py "输入.docx"
# 指定输出路径
python .cursor/skills/baidu-wenku-word-cleanup/scripts/clean_baidu_wenku_docx.py "输入.docx" -o "输出.docx"
```

3. 脚本行为：
   - 删除前 3 个段落（两行文字 + 头像图段）
   - 读取删除后首段有效标题作为文件名（优先原第 4 行，即索引 3）
   - 定位版权说明段；向前找**最后含图片的段落**，从该段起到文末全部删除
   - 输出 `{标题}.docx`（非法文件名字符替换为 `_`）

4. 无脚本时：用 `python3` + `zipfile`/`xml.etree` 按上表直接改 `word/document.xml`，再打包为 docx。

## 校验清单

处理完成后核对：

- [ ] 开头不再是「百度文库」「搜索」或头像
- [ ] 正文从试卷标题/题目开始
- [ ] 文末无「版权说明」、无「相关推荐」「猜你想看」
- [ ] 文件名与第 4 行标题一致（或用户指定的 `-o`）

## 边界情况

- **找不到版权说明**：仅删除前 3 行并重命名，保留全文其余部分，并提示用户。
- **第 4 行为空**：用 `-o` 指定输出名，或回退为原文件名。
- **输入为 `.doc`（HTML）**：先转为 `.docx` 再处理，或按同样规则解析 HTML 段落（见 [reference.md](reference.md)）。
