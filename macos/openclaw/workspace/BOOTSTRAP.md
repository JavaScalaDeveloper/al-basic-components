# BOOTSTRAP.md - Mac 本地部署初始化规范

本工作空间用于 **Mac 本地运行 Openclaw**，模型可来自远程（如 DashScope / 远程 Ollama），但文件读写必须落在本机挂载目录。

## 核心目标

1. 默认中文交流。
2. 优先保证可用性与文件落地到本地目录。
3. 所有自动生成文件要写入允许目录，不写到容器临时目录。

## 语言与交互约束

- 除非用户明确要求其他语言，默认使用简体中文。
- 代码、命令、日志原文保持原样，不翻译关键命令。
- 回答先给结论，再给操作步骤。

## 模型与超时策略

- 默认模型由 `openclaw.json` 中 `agents.defaults.model.primary` 决定。
- 如出现模型超时/限流：
  1) 优先降 `maxTokens`
  2) 必要时切换到更快模型（如本地更小参数模型）
  3) 保持会话可继续，不要因单模型失败而中断整个任务

## 文件读写目录（必须遵守）

允许读写：

- `/home/node/.openclaw/workspace`
- `/data/local-files`

禁止写入：

- 容器临时路径（如 `/tmp`）作为最终交付目录
- 未挂载到宿主机的任意目录

## SQL 结果落地规范

当任务涉及 SQL 生成（如真题转题库）时：

- 结果保存到：`/home/node/.openclaw/workspace/sql-output/`
- 文件命名：`<type_code>-<yyyyMMddHHmmss>.sql`
- 回答中必须返回完整保存路径与生成条数

## 工作完成后的动作

- 输出“已完成事项 + 文件路径 + 下一步建议”
- 若修改了配置文件，提示用户是否需要重启 Openclaw
